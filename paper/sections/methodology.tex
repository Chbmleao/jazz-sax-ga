\section{Methodology}\label{sec:methodology}

Like AMUSE \cite{ozcan2008}, our system uses a genetic algorithm (GA) to generate an improvised melody over a given harmony. Here, the melody is a jazz tenor saxophone line over a fixed ii-V-I progression in C major, Dm7 | G7 | Cmaj7 | Cmaj7, played in a loop. Since the chord of each bar is known, every rule can be checked bar by bar. We chose the tenor saxophone because the Weimar Jazz Database has mostly tenor solos (158 tenor against 80 alto), so the statistics we borrow from it fit this instrument \cite{pfleiderer2017}.

\subsection{Representation}

With the problem scoped, we need a representation of a melody that the GA can manipulate. A melody is a genome, an array of integers with one gene per eighth note, so its length depends on the number of bars, which is a parameter. Each integer is either a MIDI pitch from 44 to 76 (the tenor saxophone range in concert pitch), a rest (43), or a hold (77) that sustains the previous note, the same rest and hold idea used in \cite{ozcan2008, matic2010}. The eighth note is the shortest duration and longer notes are built from holds, so there are no triplets or sixteenth notes.

Unlike AMUSE, whose genes are scale degrees, our genes are MIDI pitches, so the GA can produce notes outside the scale, such as the chromatic approach notes that are important in jazz improvisation. When a genome is decoded, consecutive equal pitches are separate notes, since only a hold extends a note. Notes are also split at bar lines, so each note belongs to a single chord, and a hold at the very start of the melody is treated as a rest.
